# SoundWave.ipa — установка на iPhone (iOS 15–18)

**Файл:** `dist/SoundWave.ipa`

## Сразу важное

- **TrollStore (.tipa) на iOS 18 не работает** — TrollStore не поддерживает iOS 18,
  поэтому единственный путь — подписать .ipa своим Apple ID и установить как
  обычное приложение. Это делает Sideloadly или AltStore.
- Приложение **самодостаточное**: компьютерный сервер не нужен — запросы к API
  SoundCloud идут через встроенный нативный сетевой мост (без ограничений CORS),
  музыка грузится напрямую с CDN.
- **7 дней / 3 приложения** — ограничение бесплатного Apple ID. Через 7 дней
  приложение перестанет запускаться: просто подключите iPhone и повторите
  установку в Sideloadly (данные и любимые треки сохранятся).
  Платный Apple Developer (99$/год) снимает ограничение — подпись на год.

## Установка через Sideloadly (Windows, 5 минут)

1. Скачайте **Sideloadly** с https://sideloadly.io и установите.
2. Подключите iPhone к компьютеру кабелем, нажмите «Доверять» на телефоне.
3. Запустите Sideloadly:
   - перетащите `SoundWave.ipa` в окно;
   - Apple ID: введите **свой** Apple ID (email);
   - Advanced Options → оставьте по умолчанию;
   - нажмите **Start**, введите пароль Apple ID (и код двухфакторной
     аутентификации, если запрошен).
4. На iPhone: **Настройки → Основные → VPN и управление устройством →
   Apple ID → Доверять**.
5. Открывайте SoundWave с рабочего стола.

## Альтернатива: AltStore

1. Установите AltServer на компьютер (https://altstore.io) и AltStore на iPhone.
2. В AltStore: «+» → выберите `SoundWave.ipa`.

## Если что-то не так

- «Не удалось установить» — проверьте, что в Sideloadly выбран правильный
  Apple ID, и что на телефоне нет лимита в 3 сайдлоад-приложения
  (удалите лишнее).
- Приложение перестало запускаться через неделю — так работает бесплатная
  подпись, повторите установку.
- Треки не ищутся — вкладка «Ещё» → «Найти автоматически» (обновит API-ключ
  SoundCloud).

## Как это собрано

Настоящего Mac под рукой не было, поэтому .ipa собран прямо на Windows:

- `app.m` — нативная оболочка на Objective-C (UIWindow + WKWebView +
  сетевой мост WKScriptMessageHandlerWithReply + фоновая аудиосессия);
- скомпилирована кросс-компилятором Zig (clang, `aarch64-macos`) с
  самодельными .tbd-заглушками системных фреймворков;
- платформа в Mach-O пропатчена на iOS (`patch-macho.js`): arm64, PIE,
  min iOS 15;
- упаковано в `Payload/SoundWave.app` (`make-ipa.js`).

Пересборка: `node make-ipa.js` (после правок `app.m` — см. команды сборки
в истории или README проекта).
